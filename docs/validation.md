# 验收边界

v0.1.0 在维护者的 Windows 机器上进行了源码运行和界面检查，包括真实 Codex 额度、贴边条可见、四角布局、Agent 跟随启动/退出、数字框与滑条、按页/全局恢复和较大设置字体。

这些检查不代表所有 Windows 版本、DPI、显示器、游戏模式或 Codex 版本都兼容。用户确认过贴边条可见；独占全屏游戏兼容性仍需更广泛验证。

## 可重复的检查

2026-10-14 在未包含运行数据或依赖的干净源码副本上完成 `npm ci`、监听器构建和以下检查：16 项 Node 测试、9 项 C# 识别检查、51 项 Electron 界面检查通过。对应环境中的 Codex CLI 为 `0.162.0-alpha.17.2`；隔离检查本身不访问该账号。npm 官方注册表审计未报告已知依赖漏洞。

同日，首次源码提交通过 GitHub 托管 Windows runner 的安装、构建和三类测试，见 [首次云端检查](https://github.com/bin19870223-netizen/token-glance/actions/runs/38529517016)。后续提交的结果以 Actions 页面为准。

- Node 测试：数据语义、未知/零值、采样和重置、设置约束、多显示器几何、页面恢复范围、IPC 权限与取消。
- C# 测试：Codex app-server 排除、官方桌面路径识别、Claude Node 路径、自定义进程和查询字符串约束。
- Electron 检查：所有设置滑条的箭头/Enter 输入、边界、小数步进、草稿保留、按页/全局恢复、最小窗口尺寸排版。使用隔离假数据。

## v0.1.1 置顶修复与独占全屏策略

- 本机通过 37 项 Node、9 项启动监听器、8 项原生全屏分类、53 项设置界面、12 项活动面板、8 项悬停图标和 20 项 Win32 窗口检查，共 147 项。
- 实际运行的 HUD 在其他置顶测试窗口反复覆盖后恢复到前面，键盘焦点保持不变，现有设置未重置。
- Windows 原生桌面状态查询和检测进程退出已验证；独占状态转换通过模拟信号验证真实窗口撤销/恢复置顶。
- 独立测试进程遮挡后自动恢复；未遮挡时不重复提升窗口。数据广播保留悬停按钮/图标，重复悬停及鼠标未离开时的虚假离开不再反复展开/关闭。
- 24 小时按本机采样生成，覆盖首次使用、零值、断线/重启缺口、账号切换与计数重置；不将每日账单冒充滚动 24 小时。
- 未启动真实独占全屏游戏验证。检测使用 Windows 的 Direct3D 独占状态，其他图形 API 和全屏优化组合仍需实测。
- CI 增加原生窗口检查；对应提交的云端结果以 [Actions](https://github.com/bin19870223-netizen/token-glance/actions) 为准。
